# 那么该如何从零开始搓一条Ishtar的产线计划呢？

从左侧菜单栏进入工业的工业计划界面

## 1. 新建计划
![l1](/assets/doc-example-ishtar-1.png)
请勾选按照习惯分割，该选项会使计划计算时将较大的流程数按照配置分割成可执行的任务。
其他选项均需要esi调取库存，需要订阅alpha等级会员，暂时不管。

## 2. 添加产品
中间部分的当前计划下拉菜单选择刚才创建的计划。
从左侧的市场菜单中找到Ishtar，右键添加到刚才创建的计划

## 3. 计划修改

中间的计划产品处可以改变数量，可以删除，可以通过拖动改变顺序。
![l2](/assets/doc-example-ishtar-2.png)

修改后记得点击保存计划按钮，才会上传服务器。

## 4. 配置计划【重点难点】
可以先跟着做一遍，在尝试理解每一步的作用：

### 拉取推荐预设
![l3](/assets/doc-example-ishtar-3.png)
![l3](/assets/doc-example-ishtar-4.png)
点击后等待片刻。
![l3](/assets/doc-example-ishtar-5.png)
可以看到预设已经拉取，点击添加按钮将所有配置添加到刚创建的计划。
然后退出抽屉菜单，点击整理和保存。
![l3](/assets/doc-example-ishtar-6.png)

## 5. 微调配置
配置流根据顺序生效，但是添加的时候顺序不一定一致，所以需要调整

### 蓝图
可以看到，制造和研究摆在了最上面，这样会导致反应的蓝图效率被这条覆盖，因为反应材料是制造和研究的子节点。
这里需要把制造与研究拖到这4个的最后一个，另外三个影响范围互不相交，所以顺序随意，这样T1 T2船分别匹配到10-20 2-4的蓝图效率，反应则匹配到0-0。
如果你的T2使用了解码器，可以点击修改，填写对应的材料效率。
如果同一个计划中还有其他种类的船或产品，像定制化不同的蓝图效率，你需要去配置管理界面中创建一个新的蓝图配置，使用过滤器筛选你的新产品匹配范围，然后添加到最顶部优先匹配。
![l3](/assets/doc-example-ishtar-7.png)

###　作业拆分

原理与蓝图类似，我们需要把兜底的制造与研究拖到底部。
这里着重说修改。以反应举例，我个人习惯是60流程一轮，所以我点击Reaction Materials条目的作业拆分配置的修改，将最大流程改为60.这里同时有根据时间估算的选项可供选择，请根据个人的习惯进行调整。
![l3](/assets/doc-example-ishtar-8.png)
![l3](/assets/doc-example-ishtar-9.png)


### 建筑分配与建筑插
建筑分配同样遵循顺序匹配，可以指定筛选的物品去哪个建筑制造。制定后可以享受对应建筑类型和建筑插的加成。

### 最后
记得点击保存当前配置


## 6. 获得报表
最后一步，左侧进入报表，选择计划后点击立刻计算。

## 7. 按照报表推进计划
需要关注的主要是采购视图和工作流。
采购视图提供了复制一键采购材料清单的能力。
工作流提供了全流程需要进行的左右工作，可按照反应与制造分类。如果开通了alpha订阅增加库存读取，还可以筛选已经满足材料可进行的工作与缺少的蓝图。
