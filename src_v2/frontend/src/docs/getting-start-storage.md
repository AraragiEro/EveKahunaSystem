# 库存管理
库存管理需要alpha订阅,允许通过esi拉取公司或个人库存数据，用于进行更高精度和智能工业计划中的库存计算。


## 访问许可【核心】
![资产拉取图例](/assets/doc-storage-2.png)
kahunasystem的所有库存访问基于访问许可进行，这里有必要对EVE的资产数据结构进行说明。

简单的说，创建拉取任务并手动拉取了资产后，这些数据并不能马上被使用。我们实际关注的只是我们庞大资产树中的一小部分。

将这一小部分标记并筛选出来，就是访问许可的目的。

eve的资产数据结构是树形的，每个物品都会有一个父节点，一般最顶层的父节点是星系，资产树最终呈现会像这样：
- 星系A
  - 建筑A
    - 机库A
      - 物品A
      - 货柜B
        - 物品B
    - 船B
      - 装备A

这棵树的每个节点都有自己的ID，访问许可的意思就是：允许访问这个ID下的深度为1的所有资产。

还是以上面这棵树为例：
- 星系A
  - 建筑A
    - 机库A (标记访问许可：许可2)
      - 物品A (无法被许可1访问，可以被许可2访问)
      - 货柜B (标记访问许可:许可1)
        - 物品B (可以被许可1访问， 无法被许可2访问)
    - 船B (无法被许可1访问，可以被许可2访问)
      - 装备A (无法被许可1和许可2访问)

访问许可相当于给某个容器打上标记，标记后在其他场合就可以通过这个标记快速的找到我们需要关注的范围的资产：
- 例如你的公司机库
- 例如你的某个材料箱子

需要注意的是，标记基于ID，实际上公司机库的7个机库的ID是一样的，强烈建议使用货柜对机库进行整理而不是使用机库。

### 如何添加访问许可？
在库存管理的访问许可界面，有1个按钮：
- 搜索物品数目新增许可

这是目前添加许可的唯一途径。下面说原理：

若你希望添加某个容器A作为访问许可，且你知道你的容器A中有数量x的物品A，容器A位于建筑A中，那么我们就可以通过检索资产信息中的所有物品A，展示其信息和顶部建筑，从而精确定位其所属的容器ID。

有点绕，我们直接实操：

我想把我WH-JCA的制造的矿物箱子加到访问许可，且我清楚里面大约有600M单位三钛合金，那我直接搜索三钛合金：
![资产拉取图例](/assets/doc-storage-4.png)
可以看到，第一条记录就符合我的要求，他是我的目标容器的概率很大，我在标签处填写 `WH STY 材料箱子`，点击添加。

大功告成

之后在别的模块，使用`WH STY 材料箱子`就可以调用这个箱子下的所有资产。

### 如何使用访问许可？
当前有三个使用场景：
1. 工业计算中的资产导入。你可以将访问许可作为`载入库存`工业配置进行创建，使用该配置且打开了考虑库存开关的计划会自动访问该库存下的资产进行计算，清晰反映当前库存是否满足开工要求。
2. 资产浏览中可以创建视图，使用不同的试图监控资产状态，如是否缺失，估价统计等。
3. 市场分析对库存数量进行单列，方便挑选库存缺失的产品。

### 这个ID会变动吗？我需要重复操作吗？
容器一旦生成，ID便会固定，直到它被销毁。

所以访问许可大多数情况只需要设置一次。

除非你拆卸装箱你的箱子，或是建筑被解铆钉或摧毁。

PS：我没有尝试过将一个组装好的箱子从一个建筑移动到另一个建筑会不会变，等待勇敢者尝试验证。

## 资产浏览
在资产浏览界面可以配置某个访问许可的目标容器的监控视图。
视图目前有3种
- 默认
    可以显示物品种类和数量
- 销售
    会拉取物品的价格，针对销售行为做优化。可以生成共享链接让任何人访问
- 监控
    用来监控某类物品是否低于库存警戒线
