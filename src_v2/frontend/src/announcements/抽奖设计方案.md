# 🎆 EVE Online 年终抽奖活动方案（最终版）

---

# 一、活动基础信息

* 👥 参与人数：约27人
* 🎟️ 去年总业绩券：2058
* 🔁 共8轮抽奖
* 🟣 SSR大奖：

  * 1艘 万古级
  * 7艘 小旗舰
* 🔵 SR奖励：

  * 常规舰船约50条（库存有限）
* 💰 基础奖励总池：

  * 约15B ISK

---

# 二、每轮结构概览

每轮流程：

1. 玩家上报投入券数（锁定）
2. 系统计算抽数分配（最多160抽）
3. 逐次结算抽数（米池机制）
4. 统计每人获得的 SSR权重
5. 轮末进行“SSR大奖抽签（含50/50歪池）”
6. 发放SR/基础奖励/积分

---

# 三、投入券机制

## 1️⃣ 投入即返积分（防吞券）

* 每投入 1 张券 → 获得 **7M ISK 等值积分**
* 所有投入券全部消耗
* 积分用于兑换基础奖励/舰船/福利

总规模约：

2058 × 7M ≈ 14.4B ISK
接近你给的15B预算

---

## 2️⃣ 抽数总量控制

每轮抽数上限：

```
N = min(160, 本轮总投入)
```

若投入超过160：

* 仍全部消耗
* 但仅160抽进入结算池

---

# 四、抽数分配算法（防一家通吃）

使用 **平方根边际递减模型**

### Step1：计算有效投入

```
e_i = sqrt(t_i)
```

### Step2：分配抽数

```
n_i = 160 × e_i / Σe_i
```

### Step3：整数化（最大余数法）

保证总抽数 = 160

---

📌 解释：

* 投入多的人抽数更多
* 但增长是递减的
* 不会线性碾压

---

# 五、单抽结算规则（米池味核心）

每个人维护：

```
pity_count（0~79）
```

---

## SSR概率曲线

* 第1~70抽：0.4%
* 第71~79抽：线性提升至12%
* 第80抽：100%

---

## 单抽产出

### 若触发 SSR级事件（自然/80保底）

* 获得 SSR权重 +1
* pity_count 清零
* 获得 SSR事件奖励包（纪念奖励）

### 若未触发

* 获得基础奖励（5M等值）
* 可能获得SR舰船（50条库存，发完转积分）

---

# 六、SSR权重系统

* 不设个人权重上限
* 每次SSR级事件 → 权重+1
* 轮末按权重抽大奖

---

# 七、SSR最终大奖抽签机制（递归歪池版）

设：

* 每人权重 = w_i
* 总权重 = W
* 第一名权重占比 = s = w_top / W

---

## 情况1：s ≤ 50%

直接按权重比例抽出大奖

---

## 情况2：s > 50%（触发米池机制）

执行递归：

### Step1：对排名第一者进行50/50判断

* 50% → 获得大奖，结束
* 50% → 歪

### Step2：若歪

* 该玩家获得“歪补偿包”（SR自选或固定ISK奖励）
* 从名单剔除
* 回到重新计算权重比例

### Step3：终止条件

若剩余人数 = 1
→ 直接获得大奖（跳过50/50）

---

📌 效果：

* 强者有明显优势
* 但可能歪
* 弱者有逆袭空间
* 必定产生大奖得主

---

# 八、SR奖励机制

* SR舰船库存约50条
* 每轮抽数中概率触发
* 发完后转为等值积分
* 可设置每人每轮SR上限（避免集中）

---

# 九、积分系统用途

积分可兑换：

* 常规舰船
* ISK礼包
* 战备物资
* SR自选舰船
* 限量兑换奖励

---

# 十、轮次时间机制

* 每轮固定持续时间
* 投入锁定
* 不允许中途追加影响分配
* 防止冲刺破坏公平性

---

# 十一、概率与规模预期

* 每轮预计SSR权重 ≈ 4~8

* 大奖8艘

头部玩家理论中奖率不会超过 40~50%
尾部玩家仍有真实逆袭机会
