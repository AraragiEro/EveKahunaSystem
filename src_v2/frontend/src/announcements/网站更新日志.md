# Kahuna System — 完整更新记录

## 2026.05 — V1.6.0 蓝图成本计算

### 🏭 工业计划增强
- **LP蓝图成本计算**：Faction产品自动查询LP商店兑换数据，计算蓝图获取成本
  - 公式：`(LP收单价值 × LP消耗 + ISK消耗) / 单次产量`
  - 多军团竞品自动取最低LP价值
  - 成本视图中新增"蓝图成本"分类（饼图扇区 + 表格行）
  - 计划设置中新增"计算LP蓝图成本"开关

### 🛠 数据基础
- LP价值快照系统完善，支持评估值与兑换项明细查询
- LP商店前端页面，军团排名与兑换项详情
- 标准LP价值采用单品最高流水制
